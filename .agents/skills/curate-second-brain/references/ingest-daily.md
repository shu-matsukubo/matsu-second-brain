# デイリーメモ整理

## 制約

- 1回の実行で処理するデイリーメモを1ファイルに限定する。
- 対象が見つからない場合は変更せず終了する。

## 手順

1. 未処理のデイリーメモを1ファイル選ぶ。
2. 内容を読み、ナレッジ化に必要な事実を確認する。
3. 既存ナレッジへ統合するか、小さな単位のナレッジを新規作成する。
4. 必要に応じてカテゴリを選択または作成する。
5. 関連する既存ナレッジとのリンクを見直す。
6. 反映が完了したデイリーメモを `status: processed` に更新する。

事実確認ができず、信頼できるナレッジにできない場合は、メモのステータスを変更せず終了する。
