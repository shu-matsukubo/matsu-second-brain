# 会話入力の対象範囲

Notion inputの収集時とknowledgeへ整理する前に読む共通の判断基準。

対象は、ソフトウェア開発・設計・実装・テスト・レビュー・不具合調査・インフラ運用・開発ツール・開発ワークフローに直接関係する本人の意思・考え。希望・比較・否定・迷い・保留・撤回を広く拾い、長期保存価値や正式な決定であることを条件にしない。

開発に関する雑談・感想・疑問形の評価も対象。「gitってあんま良くないよねー？」は未確定の感想・疑問として扱い、Gitの客観的な欠点、利用中止の決定、明確な反対へ変えない。曖昧な支持・反対は計数しない。単なる技術質問から意欲を推測しない。

資産運用・投資判断・家計・健康・趣味・生活など開発と無関係な内容、および元発言から開発との関係を確認できない内容は収集しない。混在する発言では開発部分だけを原文のまま抜粋し、要約・背景・タイトル・会話参照にも対象外の情報を混ぜない。

整理時に対象外・関係不明の既存inputを見つけたら、理由を付けてNotionで保留にし、knowledgeへ反映しない。原文は削除・改変せず、結果説明にも対象外の内容を転載しない。その実行は保留にした一件の処理で終了する。処理中snapshotやjournalは内容をすり替えず、親Skillの安全な再開手順に従う。
