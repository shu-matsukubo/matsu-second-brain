# 会話入力の対象範囲

## 読む場面

- Notion inputの収集前
- knowledgeへの整理前

## 対象

- ソフトウェア開発・設計・実装・テスト・レビュー・不具合調査
- インフラ運用・開発ツール・開発ワークフロー
- 上記へ直接関係する本人の希望・比較・否定・迷い・保留・撤回
- 開発に関する雑談・感想・疑問形の評価

## 判断

- 長期保存価値や正式な決定であることを条件にしない。
- 単なる技術質問から意欲を推測しない。
- 「gitってあんま良くないよねー？」は未確定の感想・疑問として扱う。
- 客観的な欠点・利用中止の決定・明確な反対へ変えない。
- 曖昧な支持・反対は計数しない。

## 対象外

- 資産運用・投資判断・家計・健康・趣味・生活など、開発と無関係な内容
- 元発言から開発との関係を確認できない内容
- 混在する発言の開発以外の部分。原文・要約・背景・タイトル・会話参照にも含めない

## 整理時の保留

1. 対象外・関係不明の既存inputは、理由を付けてNotionで保留にする。
2. knowledgeへ反映せず、その一件で終了する。
3. 原文は削除・改変しない。結果へ対象外の内容を転載しない。
4. 既存snapshot/journalはすり替えず、[安全な再開手順](notion-input.md)を使う。
