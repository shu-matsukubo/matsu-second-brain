# Indexとリンクの更新

knowledgeの作成、移動、改名、分類変更、削除に伴い、Indexまたは参照リンクを実際に変更するときに読む。正しい状態は `AGENTS.md` を基準にする。

## Indexを更新する

1. 変更前後のtopicとtypeを確認し、対応する `indexes/topics/<テーマ>.md` の項目を追加、移動、更新、または削除する。
2. topic Indexがまだなく、最初の実データを登録する場合だけ新規作成する。対象knowledgeがなくなったtopic Indexは削除する。
3. `indexes/index.md` のtopicリンクも同じ作業で更新する。実データがない空の親Indexは作らない。
4. 現在の配置へ未整備のknowledgeもIndexから意図的に除外せず、内容から判断できる現在の区分へリンクする。
5. 各リンク先が存在し、knowledgeの `type` と見出し区分、`topic` とtopic Index名が一致することを確認する。

topic Indexの短い識別情報はリンク先を選ぶ補助に限定し、本文の要約や新しい知識を追加しない。

## リンクを更新する

- ファイルを移動または改名する前にリポジトリ内の参照元を検索し、主対象に直接関係する参照を同じ作業で修正する。
- タイトルを変更するときは、frontmatterの `title`、MarkdownのH1、ファイル名、Topic Indexの表示名とリンクを一致させる。対象knowledgeが持つ内部リンクと、リポジトリ内から対象knowledgeを参照する内部リンクの両方を確認する。
- 前提、判断材料、実行手順など直接の関係がある場合だけknowledge間をリンクする。相互に辿る価値がある関係は相互リンクにする。
- 関係するファイルで非標準リンクを確認した場合は、`AGENTS.md` が定める標準Markdownリンクへ整える。
- 変更後に、更新したIndexとknowledge間リンクの参照先が存在し、古いパスへの参照が残っていないことを確認する。
