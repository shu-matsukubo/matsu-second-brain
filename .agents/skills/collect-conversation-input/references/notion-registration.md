# Notion登録手順

## 接続と照合

- 接続先・ビュー: [Notion入力設定](../../../../config/notion-input.json)。
- 入力キー: `codex|<message_id>`。要約・収集日を識別子にしない。
- `keys_view_url`をviewモードでページ送りし、完了・保留を含む既存キーと照合する。
- 収集内も重複排除する。forkでも同じ発言を再登録しない。
- 作成タイムアウト後は、先にキーを照会する。
- 候補がなければ作成しない。既存項目の状態は変更しない。

## 作成

1. DBをfetchし、現在のschemaを確認する。
2. `create_pages`で次のプロパティを保存する。

| プロパティ | 値 |
| --- | --- |
| 名前 | 短い主題 |
| 状態 | 未処理 |
| 入力キー | `codex|<message_id>` |
| 入力元 | codex |
| 発言日時 | 元日時。`date:発言日時:start`と`date:発言日時:is_datetime` |
| 発言順 | 元日時のUTC ISO文字列。秒を含む |
| 原文・要約・背景 | 選んだ開発部分とその文脈 |
| 会話参照 | `source_ref`と`message_id` |

3. 本文に`## 入力記録`とJSONコードブロックを一つ置く。

| JSONキー | 値 |
| --- | --- |
| input_key | 入力キー |
| source | codex |
| source_ref | 元会話の参照 |
| occurred_at | 元の発言日時 |
| quote | 抜粋した原文 |
| summary | 確度・条件・肯定/否定を保つ要約 |
| context | 前後の本人発言に基づく背景 |

- JSONは上記7キーだけとする。
- 元の日時・原文・出典をMarkdownとして加工しない。
- プロパティは一覧用、本文JSONは取り込みの正本とする。

## 読み戻し

1. 作成ページをfetchする。
2. 本文JSONとプロパティの原文・日時・キー・未処理状態を照合する。
3. 対象外の情報が混入していないことを確認する。
4. 不一致・取得失敗を成功として報告しない。対象外の内容は結果へ転載しない。
