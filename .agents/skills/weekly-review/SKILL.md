# 第二の脳を週次レビューする

## 原則

- 第二の脳全体を俯瞰して評価する。
- `knowledge` を変更せず、週次レポートだけを作成または更新する。
- 根拠のない推測を記載しない。
- 改善を強制せず、事実と観測を分けて記載する。

## 手順

1. [ナレッジ評価観点](references/inspect-knowledge-base.md)を読む。
2. `knowledge` 全体を確認し、構成、粒度、リンクを評価する。
3. 必要に応じて `daily` や既存レポートを確認し、根拠のある活動状況だけを評価する。
4. [週次レポート形式](references/write-weekly-report.md)に従ってレポートを作成または更新する。
5. レポート以外のファイルが変更されていないことを確認する。
6. この処理で変更したレポートだけをコミットし、既存の無関係な変更を含めない。
7. 保存先と主な観測結果を簡潔に報告する。
