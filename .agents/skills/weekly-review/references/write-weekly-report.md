# 週次レポート形式

## 保存先

- `reports/weekly/yyyy`

## ファイル名

- `MM-dd.md`

## 書き込みルール

- 週ごとに1ファイル作成する。
- 同じ週のレポートが存在する場合は更新する。
- 事実と観測を記載し、改善を強制しない。
- 必要に応じて改善候補へ優先度を付ける。
- 根拠を確認できない項目は断定しない。

## フォーマット

```markdown
# MM-dd 週次レポート

## サマリー

...

## ナレッジ評価

...

## 活動状況

...

## 改善候補

### 高

-

### 中

-

### 低

-

## その他気付き

...
```
