# Agentは必要最小限にし専門性は知識で拡張する

専門性が必要になっても、専用Agentの追加を第一選択にしない。チェックリスト、レビュー観点、判断基準、Reference、Skillとして分離し、既存Agentが利用できる知識で対応できるかを先に考える。

Agentを増やすと実行コストに加えて、選択、同期、統合、責務管理の負担も増える。独立した実行主体が必要な場合だけAgentを追加し、専門能力は再利用できる知識として拡張する。
