# 上位Agentへの相談は必要時の共通能力にする

すべての処理を上位Agentへ任せず、通常のAgentが判断困難、高い不確実性、セキュリティリスク、不可逆性、または失敗時の影響が大きいと判断した場合に、助言やレビューを依頼する。

エスカレーションは特定の工程だけに限定せず、どの工程からも利用できる共通能力として扱う。相談先の上位Agentは助言とレビューを担い、元のAgentから作業主体と責任を引き継がない。
